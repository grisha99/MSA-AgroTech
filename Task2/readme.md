<h2>Задание 2. Проработка высокоуровневого видения решений</h2>

<p>Пора погружаться глубже и сформировать высокоуровневое видение на уровне контейнерной диаграммы (С2).</p>

<h5>Что нужно сделать</h5>
<ul>
    <li><b>Сформируйте ограниченные контексты,</b> которые позволят спроектировать конкретные микросервисы, и опишите их в ADR. Добавьте компромиссы и риски каждого решения.</li>
    <li><b>Составьте несколько вариантов диаграмм контейнеров.</b></li>
    <li><p>Проработайте интеграции между сервисами и сделайте обоснование выбора того или иного подхода и технологии. Зафиксируйте возникшие компромиссы.</p>
        <p>Например, для очереди мы выбрали RabbitMQ.</p>
        <p>Преимущества:</p>
        <ul>
            <li>возможность использовать MQTT для взаимодействия с устройствами;</li>
            <li>распространённая технология;</li>
            <li>не требовательна к ресурсам;</li>
            <li>поддаётся кластеризации.</li>
        </ul>
        <p>Ограничение: при определённом пороге нагрузки лучше использовать другую технологию, например Kafka.</p>
    </li>
</ul>
<p>В результате у вас должно получиться две диаграммы C2 — по одной для каждого возможного решения и ADR.</p>
