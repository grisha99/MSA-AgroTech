<h2>Задание 4. Проработка критериев выбора решения</h2>

<p>Бизнесу важно выбрать конкретное решение.</p>
<h5>Что нужно сделать</h5>
<ul>
<li>Сформируйте критерии для сравнения двух решений.</li>
<li>Проанализируйте каждый вариант по выделенным критериям.</li>
<li>Резюмируйте, какое решение вы рекомендуете.</li>
</ul>
<p>Добавьте это в ADR.</p>
<p>В результате у вас должны быть ADR с критериями для сравнения каждого решения, анализом ваших вариантов системы по ним и личным резюме.</p>
